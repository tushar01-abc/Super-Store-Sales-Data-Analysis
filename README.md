# Super-Store-Sales-Data-Analysis
### 📌 Project Overview

The Super Store Sales Dashboard is an end-to-end data analytics project built to analyze sales performance, profit trends, customer segments, shipping modes, and regional growth using real-world retail data.

This project demonstrates skills in:

Data Analysis

Business Intelligence

Dashboard Design

Sales & Profit Insights

#### 🎯 Project Objectives

Analyze overall sales, profit, and quantity trends

Identify top-performing regions and states

Compare monthly sales and profit year-over-year (YoY)

Understand customer segments and payment modes

Evaluate shipping methods and product categories

Provide actionable business insights

#### 🛠️ Tools & Technologies Used

Database: PostgreSQL

Data Analysis: SQL

Data Visualization: Power BI

Dataset: Super Store Sales Dataset

Version Control: Git & GitHub
